# Alur Film Realtime Video Splitter & Chunk Progress Design

## Overview
Enhance the Alur Film Flow 1 Master Video Splitter in the desktop dashboard so that video splitting progress is reported in real-time. Video chunks generated by FFmpeg will be pushed to the UI list immediately upon completion, accompanied by real-time progress calculations (current part / total parts, percentage) and an in-progress placeholder card in the UI list.

## User Intent & Requirements
- **Real-time Splitting Progress**: Display the progress of video splitting in the UI as it happens (e.g., "Memotong Part 2 dari 5 (40%)").
- **Live Chunk Append**: Add each newly split video chunk to the UI list immediately as soon as its individual FFmpeg cut completes, rather than waiting for all cuts to finish.
- **Chunk Counter & In-Progress Indicator**: Show how many total chunks will be produced and track completed vs remaining chunks. Show an animated placeholder item for the chunk currently being processed in the chunk list.

## Architecture & Data Flow

### 1. Main Process (`dashboard/electron/ipc/alurfilmHandlers.cjs`)
- Update `splitAlurfilmVideoHelper` to accept the IPC `event` parameter.
- Calculate `numParts = Math.ceil(totalRangeSec / chunkDuration)` upfront before beginning the splitting loop.
- Emit progress events over IPC channel `'alurfilm-split-progress'` to `event.sender`:
  - **`start`**: `{ status: 'start', currentPart: 0, totalParts: numParts }`
  - **`splitting`**: `{ status: 'splitting', currentPart: i + 1, totalParts: numParts }`
  - **`chunk_completed`**: `{ status: 'chunk_completed', currentPart: i + 1, totalParts: numParts, chunk: createdChunk }`
  - **`done`**: `{ status: 'done', currentPart: numParts, totalParts: numParts, chunks: createdChunks }`

### 2. Preload Bridge & Electron API (`dashboard/electron/preload.cjs` & `dashboard/src/electron-api.ts`)
- Add `onAlurfilmSplitProgress` in `preload.cjs` exposing listener registration and cleanup:
  ```javascript
  onAlurfilmSplitProgress: (callback) => {
    const handler = (_event, data) => callback(data);
    ipcRenderer.on('alurfilm-split-progress', handler);
    return () => ipcRenderer.removeListener('alurfilm-split-progress', handler);
  }
  ```
- Declare TypeScript interfaces and method signature in `electron-api.ts`:
  ```typescript
  export interface AlurfilmSplitProgressPayload {
    status: 'start' | 'splitting' | 'chunk_completed' | 'done';
    currentPart: number;
    totalParts: number;
    chunk?: AlurfilmChunk;
  }
  ```

### 3. Frontend UI Component (`dashboard/src/components/longform/AlurfilmSplitterStep.tsx`)
- Manage real-time state `splitProgress`:
  ```typescript
  interface SplitProgressState {
    isSplitting: boolean;
    currentPart: number;
    totalParts: number;
    percentage: number;
    statusText: string;
  }
  ```
- Subscribe to `api.onAlurfilmSplitProgress` during splitting:
  - On `'start'`: Reset `chunks` to `[]`, initialize progress state.
  - On `'splitting'`: Update `currentPart` and `percentage`.
  - On `'chunk_completed'`: Append newly created `chunk` to `chunks` list in state without waiting for total completion.
  - On `'done'`: Complete progress state, enable controls.
- **UI Elements**:
  - **Header Counter**: Displays real-time chunk progress e.g., `✓ 2/5 Parts Split`.
  - **Control Box Progress Bar**: Displays an active progress bar with smooth CSS width transition, percentage indicator, and current part status text during splitting.
  - **Right Panel Chunk List**:
    - Renders completed chunk cards.
    - Appends an animated **In-Progress Card Placeholder** (`P[currentPart]`) with a loading spinner while `splitting` is active.
